# CS Arsenal — CS2-геймплей для Minecraft 1.21.1 (NeoForge)

## Что внутри
- **Весь арсенал CS2:** 10 пистолетов, 7 ПП, 7 винтовок, 4 снайперки, 6 единиц тяжёлого оружия, нож (+керамбит), Zeus x27, 6 гранат, C4, бронежилет, шлем, набор сапёра.
- **Параметры CS2:** урон, бронепробитие, падение урона с дистанцией (range modifier), скорострельность, магазин и запас, время перезарядки, скорость бега с каждым оружием, неточность (стоя, сидя, в движении, в прыжке, после выстрела), восстановление точности.
- **Сабтик-стрельба.** Выстрел считается в кадре нажатия, с точными углами обзора, а не на тике 20 Гц. Хит-детекция идёт по тем же позам, что видит игрок; сервер валидирует попадания и пересчитывает прострел стен.
- **Спрэй-паттерны.** Модель aim punch как в CS: пуля летит в `view + 2 × punch`, камера показывает 45 % отдачи, распад отдачи exp 8 и lin 18. Для AK, M4A4 и M4A1-S паттерны заданы вручную, для остального оружия генерируются процедурно.
- **Прострел стен.** Используется формула CS:GO и материалы блоков: дерево, бетон, металл, стекло, грунт; обсидиан и бедрок не пробиваются. Стекло бьётся (настраивается).
- **Броня.** Кевлар и шлем работают по формуле CS. Урон по зонам: голова ×4, живот ×1.25, ноги ×0.75.
- **Мувмент Source/CS2:** friction 5.2, accelerate 5.5, airaccelerate 12 (стрейфы и бхоп), stopspeed 80, прыжок 57 юнитов, гравитация 800, стамина. Скорость зависит от оружия; Shift — бесшумный шаг (52 %), Ctrl — присед (34 %). Спринта нет. Субтик-ввод: физика считается в 3 подшага за тик с долями нажатия клавиш.
- **Новый персонаж:** гладкая модель оперативника T/CT со скелетом. Позвоночник гнётся за прицелом, стойка с разворотом плеч, руки держат оружие через IK, ноги шагают процедурно. **Хитбоксы (голова, шея, грудь, живот, таз, руки, ноги) привязаны к тем же костям**, поэтому совпадают с анимацией. F3+B показывает хитбоксы.
- **Вьюмодель:** руки в перчатках и анимации доставания, отдачи (затвор, слайд), перезарядок по семействам, передёргивания затвора AWP и SSG, осмотра (F), ножа, гранат, накручивания глушителя. Покачивание при ходьбе и инерция от мыши.
- **Гранаты:** HE (гауссово падение урона, стены блокируют урон), флешка (учитывает угол взгляда), дым (объёмный, заполняет пространство, простреливается, HE его раздувает, тушит молотов), молотов и зажигательная (огонь растекается по полу), декой.
- **C4:** закладка за 3.2 с, таймер, ускоряющийся писк, разминирование 10 с (5 с с набором).
- **HUD:** HP и броня, патроны, прицел CS (динамический или статический), оверлеи AWP и AUG, килфид (в голову, сквозь стену, без прицела, сквозь дым, ослеплённый, в воздухе), имя игрока под прицелом.
- Все 3D-модели, текстуры и звуки созданы процедурно (`tools/`). Ассеты Valve не используются.

## Управление
| Клавиша | Действие |
|---|---|
| ЛКМ | Огонь / удар ножом / сильный бросок гранаты |
| ПКМ | Прицел (зум), глушитель, режим очереди, укол ножом, слабый бросок |
| ЛКМ + ПКМ | Средний бросок гранаты |
| R | Перезарядка |
| F | Осмотр оружия |
| Shift | Бесшумный шаг |
| Ctrl | Присесть |
| B | Меню закупки |
| G | Выбросить оружие |
| ПКМ (удерживать) с C4 | Заложить бомбу; по заложенной бомбе — разминировать |

## Команды
- `/cs team t|ct|none` — выбрать команду (скин оперативника, огонь по своим).
- `/cs armor <0-100> [helmet]` — выдать броню.
- `/cs refill` — пополнить патроны.

## Сборка
```
cd csarsenal
python3 tools/build_assets.py   # пересобрать модели, текстуры и звуки (нужны numpy, scipy, pillow, soundfile)
./gradlew build                  # готовый jar: build/libs/csarsenal-1.0.0.jar
```
